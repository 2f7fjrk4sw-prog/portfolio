Yetkinlikler & Yaklaşım

Yapay yüzdelik çubukları yerine gerçek hayatta ve projelerimde kullandığım araçlar ve mühendislik prensipleri.

Programlama Dilleri

  • C#
    Nesne yönelimli programlama (OOP), tip güvenliği, LINQ, bellek yönetimi ve algoritmik problem çözme.
  • JavaScript (ES6+)
    Modern JS standartları, asenkron akışlar (Promises, Async/Await), DOM manipülasyonu.
  • SQL
    İlişkisel veritabanı tasarımı, normalizasyon, CRUD işlemleri ve veri bütünlüğü.
  • HTML5 & CSS3
    Anlamsal semantik etiketleme, modern Flexbox & Grid yerleşimleri, responsive arayüzler.
›

Oyun & Platformlar

  • Unity Engine (Orta Seviye)
    C# script mimarisi, 2D/3D mekanikler, fizik motoru, sahne optimizasyonu ve UI Canvas tasarımı.
  • .NET & .NET Core
    Konsol sistem araçları, ASP.NET Core Web API temelleri, çoklu platform desteği.
  • Node.js
    İstemci/sunucu mimarisi, REST servisleri, JSON veri akışları ve npm yönetimi.
  • Git & Versiyon Kontrol
    Branching modelleri, commit disiplini, GitHub iş akışları ve takım çalışmaları.

Mühendislik Pratikleri

  • Temiz Kod (Clean Code)
    Kendini açıklayan isimlendirmeler, modüler fonksiyonlar ve tek sorumluluk prensibi.
  • Defansif Programlama
    Uç durumlar, beklenmeyen girdiler ve tip uyumsuzluklarına karşı dayanıklı kod tasarımı.
  • YAGNI & KISS İlkeleri
    Gereksiz soyutlamalardan ve erken optimizasyon tuzaklarından kaçınarak yalın kalma.
  • Hafif Siklet Tasarım
    Gereksiz devasa paketler yerine saf web standartlarını kullanarak yüksek hız ve verimlilik.
